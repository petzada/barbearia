# 0020 — Cadastro aberto; admin gerencia assinaturas no backoffice

- **Data:** 2026-10-13
- **Status:** aceita (sujeita ao teto da [0061](0061-teto-de-assinaturas-por-plano.md) e aos limites da [0060](0060-limites-de-uso-e-de-reserva.md))
- **Substitui:** a parte de "assinatura só para clientes habilitados" de [0013](0013-sem-avulso-assinatura-para-clientes-escolhidos.md)

## Decisão
- **Qualquer cliente com o link** pode criar conta, fazer login, **assinar planos** e **marcar horários**. Não existe habilitação prévia pelo admin.
- O admin **visualiza e gerencia** as assinaturas num **backoffice no estilo CRM de clientes**, como os concorrentes profissionais (lista de clientes, assinatura, histórico, pagamentos, sinalizações).

## Consequências
- Sem o controle "cliente habilitado para assinar".
- Pagamento avulso: só na barbearia, com registro no app ([0029](0029-avulso-presencial-e-confirmacao-de-atendimento.md)).

## Revisão adversarial (2026-10-13)
- Cadastro aberto mantido, sujeito ao teto opcional de assinaturas ([0061](0061-teto-de-assinaturas-por-plano.md)) e aos limites de reserva ([0060](0060-limites-de-uso-e-de-reserva.md)).
