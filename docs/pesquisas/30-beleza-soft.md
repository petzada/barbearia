# Beleza Soft

Programa para salão de beleza, com download local. Fora do desenho mobile-first de uma loja. A página de download oferece 30 dias de teste. WhatsApp, Pix, clube e API: não confirmados.

## O que é e para quem

Software de salão para instalar. A página “em que estamos trabalhando” ainda lista “agendamento online” e uso em smartphones como trabalho planejado, no meio de um changelog de coisas já feitas. Data da página: desconhecida. Página possivelmente desatualizada. Tratar agendamento online e app como não confirmados no produto instalável.

## Features que importam para uma loja só

Agenda local, clientes, profissionais, comandas e caixa. Nada disso está descrito como página no celular do cliente. O roadmap ainda trata agendamento online como trabalho planejado.

## Objeções e reclamações observadas

Não há reclamação de usuário com URL nas páginas do produto.

## O que copiar e o que deixar de fora

Deixar o produto instalável de fora do formato. O que a lista de funções confirma é o miolo de salão (agenda, comanda, caixa) que os sistemas em nuvem também têm. Sem link do cliente confirmado, não há o que reaproveitar no web app além dessa lista de cadastros.
