# Belasis

Gestão para salão, barbearia e clínica de estética. Claim de mais de 16.000 profissionais. Telefones de venda e suporte publicados: 49 2398-0065 e 49 2398-0063. Não é descrito como marketplace.

## O que é e para quem

Três cards de plano na página de preços: Lite, Pro e Scale. Há programa de revenda. O cliente é descrito por “site de agendamento online” na tabela comparativa, sem plano identificável no texto extraído. White-label de rede e “aplicativo próprio da rede” também estão na tabela, sem plano identificável. Não atribuir esses itens a um plano específico.

## Como vendem

Página oficial ([preços](https://www.belasis.com.br/precos)):

- Lite a partir de R$ 99/mês no cartão recorrente: agenda no computador e no celular, comandas, CRM, vendas por assinatura, relatórios.
- Pro a partir de R$ 189/mês: o card diz tudo do Lite, comissões automáticas, financeiro de entradas e saídas, CRM completo e anamneses.
- Scale sob consulta: faturamento anual, assistente de IA, automações, API pública e gerente de conta.

“Testar grátis” no Lite e no Pro. “Falar com vendas” e demonstração no Scale.

## Features que importam para uma loja só

Vendas por assinatura já aparecem no card do Lite, o plano de entrada. Comissões automáticas só entram no texto do Pro. A tabela comparativa da mesma página lista clube, sinal, WhatsApp API oficial, white-label e aplicativo próprio da rede, mas o texto publicado não deixa claro em qual plano cada asterisco liga. API pública está confirmada só no card do Scale, sob consulta. PIX, Mercado Pago e PWA: não confirmado. Nenhuma dessas páginas publica documentação de API além dessa menção.

## Objeções e reclamações observadas

Não há reclamação de usuário com URL nas páginas do produto.

## O que copiar e o que deixar de fora

Copiar a ideia de venda por assinatura no plano que a loja realmente usa, não num módulo de rede. Deixar de fora white-label e API pública: na página eles não estão amarrados ao Lite, e a API só está explícita no Scale sob consulta. Não tratar clube, sinal e WhatsApp oficial como inclusos no R$ 99 até a tabela ligar cada linha a um plano.
